# .claude/hooks/domain-map.txt
#
# Maps source-file path patterns to the domain runbook that should be
# updated when that pattern is touched. Used by pre-pr-check.sh to enforce
# CLAUDE.md rule 19/36 (doc-updates ship in the same PR as code).
#
# Format:
#   <pattern>|<runbook>
#
# Patterns are bash-glob-style, matched against `git diff --name-only`
# output. Order matters -- more-specific patterns first; the first
# matching line wins. This repo is App Router (app/src/app/**) with a
# REST API retained under app/src/pages/api/** and typed reads/writes
# under app/src/server/trpc/** -- most domains touch two or three of
# those trees plus a lib/ module, so each domain has entries in each.
#
# Add a new line whenever a new domain gains a runbook. If you change
# code in a path that has no mapping here, the hook treats it as
# "miscellaneous" -- touching CLAUDE.md, ROADMAP.md, OR any file under
# docs/ is enough to satisfy the gate.
